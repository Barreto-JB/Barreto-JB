# Technology icons

Icons are checked in from [Devicon](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons), under the included [MIT license](LICENSE.devicon.txt).

The GitHub icon uses a light foreground on a dark tile for visibility in both GitHub themes. The PostgreSQL icon labels SQL in the language grid and PostgreSQL in the database grid. These represent the SQL migrations and Supabase database in the public English Journey project.
